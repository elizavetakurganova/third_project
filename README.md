# Проект: Путешествие по России

## Автор проекта
Елизавета Курганова
группа ИД22-3

## Описание проекта
Проект "Путешествие по России" представляет собой адаптивный сайт, посвященный туристическим возможностям и красотам России. Цель проекта – вдохновить пользователей на путешествия по стране, показать разнообразие регионов и предоставить полезную информацию для планирования поездок.

## Функциональность
Фотогалерея с изображениями природы России.
Разделы с описанием популярных туристических маршрутов и направлений.
Советы и рекомендации для путешественников по России.

## Используемые технологии
HTML5: для создания структуры и разметки страниц.
CSS3: для стилизации и адаптивного оформления сайта под различные устройства.
